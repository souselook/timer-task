# ⏰ TimerTask — таймер действий для Windows

Небольшое приложение: задаёте время, выбираете действие (выключение ПК, выход из системы, сон, перезагрузка или своя команда) — по истечении таймера действие выполняется.

## Скачать готовый EXE
Самая свежая версия — в разделе **Releases**:
👉 https://github.com/souselook/timer-task/releases/latest

Файл портативный, установка не нужна. Если Windows SmartScreen предупредит (файл без подписи): «Подробнее» → «Выполнить в любом случае».

## Как это работает
1. Окно настройки: поле времени ЧЧ:ММ:СС, кнопки −/+ и сетка быстрых пресетов (5с … 2ч), выбор действия, большая кнопка СТАРТ.
2. После старта окно плавно гаснет и появляется **красный таймер поверх рабочего стола** (прозрачный фон, без чёрного экрана).
3. Последние 10 секунд цифры мигают. По истечении действие выполняется сразу (без окна подтверждения).
4. Отмена: Esc или клик по цифрам таймера.

Поддерживаемые действия: Выключение ПК, Перезагрузка, Сон, Выход из системы, Запустить программу, Предпросмотр (безопасно), а также произвольная команда.

## Сборка из исходников (Windows 10/11)
```
pip install pyinstaller
pyinstaller --onefile --windowed --name TimerTask timer_task.py
```
Готовый файл: `dist\TimerTask.exe`. Или просто push в `main` — GitHub Actions соберёт EXE сам (workflow Build Windows EXE).

## Консольный режим
```
python timer_task.py --cli --time "5 мин" --action shutdown [--dry-run]
```
